Cómo conectar
  1. Cree una hoja de cálculo en Google Drive.
  2. Abra Extensiones › Apps Script y pegue el archivo Codigo_AppsScript.gs de esta carpeta.
  3. Implementar › Nueva implementación › Aplicación web. Ejecutar como: Yo. Acceso: Cualquier persona.
  4. Copie la URL /exec, péguela arriba y pulse Probar conexión.

4. Datos de este equipo

Buenas prácticas aplicadas en esta app

  • Integridad de datos (ALCOA+). Cada registro queda atribuido a un usuario, con fecha y hora automáticas, origen del dato (manual, voz, foto, escáner), firma y versión. Corregir exige un motivo y queda en la hoja «Auditoría»; los registros no se borran, se anulan.
  • Opciones fijas en vez de texto libre. C/NC, Sí/No y dictámenes como botones grandes, para que los datos se puedan analizar.
  • Llenado guiado por pasos. Datos generales → mediciones → verificaciones → cierre → revisión, con avance visible y validación al terminar cada campo.
  • Pensado para la planta. Botones grandes para manos con guantes, dictado por voz, cálculos automáticos y «Repetir último».
  • Funciona sin señal en cámaras de frío y contenedores: guarda en el equipo y envía cuando vuelve la conexión.
  • Del papel a lo digital. La foto de un formato se lee con OCR y usted confirma los valores. Se recomienda usar papel y app en paralelo una o dos semanas.
  • No conformidad → acción correctiva. Ante un NC o un valor fuera de rango, la app propone abrir el R-21 ya prellenado.
